# دستور وخريطة عمل استوديو الفيديو الذكي
# AI Video Studio — Mission, Architecture & Master Intake Framework

> **توجيه موجه إلى Antigravity / AI Agent:**
> هذا الملف هو "الدستور الإرشادي والميثاق الإخراجي" لهذا الاستوديو. يوثق هذا المستند فلسفة العمل المعتمدة، وهندسة الكبسولة المستقلة للمشاريع (Clean Capsule Architecture)، والبرومبت الاحترافي الذكي الشامل (Master Video Intake Prompt) الذي يضمن حصر كافة تفضيلات المخرج والمستخدم في ضربة واحدة لمنع التكرار وسوء الفهم.

---

## 1. الرؤية وفلسفة الإخراج (Core Philosophy)

نحن لا نصنع فيديوهات تقليدية ولا نعتمد على برامج المونتاج الروبوتية الجافة؛ نحن ندير **استوديو مونتاج برمجي متكامل (Programmatic Motion Graphics Studio)**:
* **الفلسفة الأساسية:** الفيديو هنا يُبنى بالكود (`React + Remotion`) ويتحرك بالفيزياء المرنة (`Spring Animations`)، ويتزامن مع الصوت بدقة الفريم بالاعتماد على نماذج الذكاء الاصطناعي (`Whisper`).
* **القاعدة الجوهرية (Literal Visual Simulation):** الشاشة مخصصة للمشاهدة لا للقراءة. رسم العناصر الحية التي يذكرها الصوت فوراً وتفاعلياً (عنوان + رسم توضيحي تفاعلي فقط بدون بطاقات نصية أو فقرات كلامية).

## 2. البرومبت الاحترافي الذكي المانع للتكرار (Master Video Intake Prompt)

> [!IMPORTANT]
> **برومبت الإنتاج الشامل (Single-Shot Master Prompt):**  
> انسخ هذا البرومبت بالكامل واملأ بيانات الفيديو الجديد لتبدأ عملية الإنتاج فوراً بدقة تامة وبدون الحاجة لأي مراجعات أو تكرار:

```markdown
بصفتك المخرج التقني والإبداعي (Creative Technical Director) لاستوديو الفيديو البرمجي، قم بإنشاء وإخراج فيديو موشن جرافيكس سينمائي احترافي جديد وفق الهوية البصرية الرسمية والمعمارية النظيفة للكبسولة المعزولة، مع الالتزام التام والكامل بالبيانات والمحددات التالية:

1. [بيانات الفيديو ومسارات الملفات]:
   - اسم المشروع / المجلد: [Projects/Video_XX_Name]
   - ملف الفويس أوفر (Audio): [Raw_Footage/audio/voiceovers/XXX.mp3]
   - ملف تفريغ Whisper الزمني: [Raw_Footage/transcripts/XXX.json]
   - مقاس الشاشة: 1080x1920 (Shorts/Reels 9:16) بمعدل 30 FPS.

2. [العناوين والتايبوجرافي (Free Floating Typography)]:
   - العناوين الرئيسية حرة تماماً في أعلى الشاشة وبدون أي بوكسات أو حاويات أو خلفيات ملونة خلفها.
   - النص ثقيل وفخم بصرياً (Cairo 800/900).
   - كتابة المصطلحات التقنية والمعمارية البرمجية بالإنجليزية بخط عريض، مع ترجمة توجيهية عربية خفيفة فقط.

3. [التمثيل البصري الحي والتحول التفاعلي (Literal Visual Simulation)]:
   - ممنوع منعاً باتاً وضع بطاقات مستطيلة تحتوي كلاماً كبديل عن الرسم.
   - ارسم المكون الحقيقي المذكور نصاً (ذكر كمبيوتر -> رسم كمبيوتر، ذكر معالج -> رسم CPU ومسارات نحاسية، ذكر كود -> رسم نافذة كود مصغرة، ذكر داتابيز -> رسم أسطوانة قاعدة بيانات، ذكر راوتر وهاتف -> رسمهما مع تدفق حزم البيانات).
   - المشهد حي وتفاعلي (Interactive Dynamic State): إذا قيل "قسمنا" تنقسم الكتلة أمام المشاهد، إذا قيل "تواصل" تتدفق النبضات فوراً.
   - ممنوع المشاهد الثابتة (Zero Static Scenes): المشهد يتحول ويتفاعل مع كل جملة صوتية.

4. [سياسة الإيموجي الصارمة (Strictly Zero Emojis)]:
   - استخدام حصري لأيقونات الفيكتور الهندسية البرمجية الدقيقة (SVG). ممنوع استخدام أي إيموجي على الإطلاق.

5. [المقارنات والمميزات والعيوب (Pure Visual Metaphors)]:
   - تمثيل المفاضلة بصرياً بميزان ميكانيكي هندسي أو مؤشرات سرعة أو أدوات فحص فيكتور، دون سرد بطاقات وقوائم نقطية.
   - إذا لزم وجود مؤشر، يكون كلمة واحدة فقط حرة بدون خلفية (مثل: المميزات • / العيوب •).

6. [تسلسل الظهور التدريجي الختامي (Sequential Progressive CTA)]:
   - في مشهد الختام ودعوة التفاعل، الالتزام الصارم بالظهور التدريجي على 3 مراحل متزامنة مع الصوت:
     المرحلة الأولى: تظهر فقط المنصات/الخيارات للمقارنة، مع زوم وتوهج منفرد لكل خيار لحظة نطق اسمه.
     المرحلة الثانية: عند نطق "اكتبلي في الكومنتات" يظهر صندوق التعليق العصري ويكتب تلقائياً أمامه.
     المرحلة الثالثة: عند نطق "واعمل فولو وسيف" تظهر أزرار المتابعة والحفظ والمشاركة وتتفعل فورياً.

7. [الكابشن الحركي وشريط التقدم]:
   - كابشن كاريوكي حر في الثلث السفلي بدون أي خلفية أو صندوق، بخط معتدل (32px)، وتتلون الكلمة الحالية لحظة نطقها بلون التيراكوتا (#D65A2C).
   - شريط تقدم سفلي تماماً مع كرة ثلاثية الأبعاد (بيلية متدحرجة مجسمة بتظليل واقعي) تسير طوال مدة الفيديو.

8. [الخلفية الهندسية الحية (The Living Architectural Canvas)]:
   - أرضية دافئة بلون الورق الهندسي (#F4EFEB)، مع تنفس ضوئي وتدرجات ناعمة في الزوايا، وحزم بيانات ونبضات ضوئية ميكروية تسير بهدوء على خطوط الـ Blueprint Grid، ونبضات لعلامات التقاطع (+).

9. [المعمارية النظيفة وحذف المعاينات المؤقتة]:
   - بناء وتوطين كافة أكواد ومشاهد المشروع بالكامل ككبسولة مستقلة داخل مجلد [Projects/Video_XX_Name/src/].
   - الإبقاء على مجلد Projects/remotion كـ Pure Runner نقي لا تتراكم داخله ملفات المشاهد.
   - أي لقطة معاينة (Preview still) تؤخذ لفحص العمل، تُحذف وتُمحى فوراً ولا يُترك أي ملفات صور مؤقتة محفوظة.
```

## 3. هندسة الكبسولة المستقلة للمشاريع (Clean Capsule Architecture)

لضمان العزل التام ومنع تلوث الأنماط والستايلات بين المشاريع، يُبنى كل فيديو داخل مجلد مستقل تماماً:

```text
📁 Projects/
   ├── 📁 Video_Name/                           # كبسولة الفيديو المستقلة بالكامل
   │   ├── 📄 storyboard.md                    # تخطيط وسيناريو المشاهد
   │   └── 📁 src/
   │       ├── 📄 index.ts                     # نقطة التصدير الموحدة للكومبوزيشن
   │       ├── 📄 MainComposition.tsx          # المجمع الرئيسي لتايم لاين الفيديو
   │       ├── 📄 Thumbnail.tsx                # تصميم صورة الغلاف المصغرة
   │       ├── 📄 timeline.ts                  # الفريمات والأحداث الصوتية SFX
   │       ├── 📄 captions.ts                  # تفريغ الكلمات وتوقيتات الكابشن
   │       ├── 📄 brand_tokens.ts              # متغيرات الهوية الرسمية (الألوان والخطوط)
   │       │
   │       ├── 📁 scenes/                      # ملفات المشاهد التنفيذية (Scene01, Scene02...)
   │       └── 📁 components/                  # المكونات الهندسية، الرسوم الحية، والكابشن
   │
   └── 📁 remotion/                            # محرك التشغيل والرندر النقي (Pure Runner Engine)
       ├── 📄 package.json                     # الحزم ومكتبات Remotion
       └── 📁 src/
           └── 📄 Root.tsx                     # يقوم باستدعاء الكومبوزيشن من كبسولته المعزولة:
                                               # import { MainComposition } from "../../Video_Name/src";
```

## 4. الأركان الخمسة لمساحة العمل (The 5 Pillars)

1. **`Setup_and_Tools/`**: بيئة التشغيل، سكربتات التفريغ الصوتي بـ Whisper، ومحركات الفيزياء.
2. **`Reference/`**: المرجع الوحيد؛ يحتوي حصرياً على الهوية الثابتة (`Reference/00_My_Brand_Identity/`) والمراجع المعزولة (`Reference/Style_XX/`).
3. **`Raw_Footage/`**: المواد الخام الخارجية فقط (الفويس أوفر، الموسيقى، المؤثرات SFX، تسجيلات الشاشة، وتفريغات Whisper).
4. **`Projects/`**: كبسولات المشاريع المستقلة البرمجية؛ لا تداخل بين مشروع وآخر، وRemotion نقي ومجرد.
5. **`Exports/`**: المخرجات النهائية الجاهزة للنشر فقط (`shorts_reels/`, `youtube_full/`, `thumbnails/`).

---

## 5. ميثاق الجودة الصارم (Zero-Defect Protocol)

1. **صفر إيموجي (Zero Emojis):** لا يُسمح بإيموجي في أي مشهد أو كود أو واجهة.
2. **صفر مشاهد ثابتة (Zero Static Scenes):** كل مشهد يتحول ويتفاعل مع حركة الفويس أوفر.
3. **صفر صور معاينة متبقية (Zero Preview Leftovers):** أي صورة تُستخرج للمعينة الفورية تُمسح وتُحذف فوراً بعد التحقق.
4. **عناوين حرة (Free Typography):** وزن خط عالي، وضوح تام، وصفر بوكسات خلفية.
